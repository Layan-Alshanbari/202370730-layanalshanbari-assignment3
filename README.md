# Personal Portfolio – Assignment 3

## Project Description

This project builds on my Assignment 2 portfolio using HTML, CSS, and JavaScript. It displays my public GitHub repositories, which visitors can sort by creation date. It also includes categorized project filters, a validated demo contact form, and a light/dark theme that remembers the visitor’s choice.

## Features

- About Me and Projects sections
- SWE and COE project filters
- GitHub repositories loaded from the GitHub API
- Sort repositories by newest or oldest
- Contact form validation and confirmation; the demo does not send messages
- Responsive design and hover effects
- Light and dark themes with the visitor’s choice saved


## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub REST API
- Browser localStorage
- IntelliJ IDEA

## How to Run Locally

1. Clone the repository or download and extract it.
2. Open the project folder in IntelliJ IDEA.
3. Open a terminal in the project folder and run `python3 -m http.server 8000`.
4. Visit [http://localhost:8000](http://localhost:8000) in your browser.
5. Press `Ctrl+C` in the terminal to stop the server.
